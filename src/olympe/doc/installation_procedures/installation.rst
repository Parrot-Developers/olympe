Installation
============

Installing the latest Olympe version on Ubuntu 22.04 (on x64) or higher is done at its
simplest with the provided pre-built wheel. Installation of Olympe from pre-built wheels
requires `pip` version 20.3 or higher.
Check our detailed installation procedure :ref:`here <installation_prebuilt_wheel>`.

Alternatively, you can also :ref:`build Olympe from source <installation_build_from_source>`.

There is no pre-built Olympe release for ARM targets (aarch64, armv7, ...).
To use Olympe on an ARM device, you need to build it from source.

If you need some guidance to set up your Python virtual environment, you should check our
Python environment setup :ref:`best practices <python_environment_best_practices>`.
